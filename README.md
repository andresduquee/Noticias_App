Proyecto: Buscador de Noticias Internacionales con React
Integrantes: Andres Duque, Bryan Mayo, Jorge Ivan Marin, Andres Marulanda
Profesor: German Adolfo Franco Posada
Descripción del Trabajo

El estudiante deberá desarrollar una aplicación web en React.js que permita consultar y mostrar las noticias más recientes de diferentes categorías utilizando una API pública de noticias.
El usuario podrá seleccionar una categoría (por ejemplo: tecnología, deportes, salud, entretenimiento, ciencia o negocios) y, al presionar un botón, la aplicación mostrará las noticias correspondientes.

Objetivo

Poner en práctica el manejo de eventos y estados en React mediante el consumo de una API pública, sin emplear el hook useEffect.
El proyecto debe evidenciar la capacidad del estudiante para controlar la interacción del usuario y representar información dinámica proveniente de fuentes externas.

Requisitos Funcionales

La aplicación debe permitir seleccionar una categoría de noticias desde un menú desplegable.

Al presionar un botón, se debe consultar la API y mostrar las noticias más recientes de esa categoría.

Cada noticia debe mostrar al menos:

Título.

Fuente o autor.

Imagen destacada (si está disponible).

Enlace al artículo original.

Si no se encuentran noticias o ocurre un error, se debe mostrar un mensaje al usuario.

Debe mostrarse un mensaje o animación mientras se cargan los datos.

La interfaz debe ser agradable, clara y adaptarse a diferentes tamaños de pantalla.

Requisitos Técnicos

El proyecto debe ser creado en React.js con componentes funcionales.

Se debe utilizar exclusivamente el hook useState para manejar los estados.

Las solicitudes a la API deben hacerse con fetch() dentro de una función activada por el evento del botón.

La API a utilizar será NewsAPI (https://newsapi.org
) o una alternativa gratuita como Mediastack o GNews.

Se debe usar Bootstrap 5 para estructurar y estilizar la aplicación.

Requisitos de Entrega

Subir el proyecto a un repositorio público en GitHub.

Incluir un archivo README.md con la descripción del proyecto, la API utilizada y los pasos para ejecutar la aplicación.

Agregar capturas de pantalla o un video corto que muestre la interacción del usuario y los resultados obtenidos.

Criterios de Evaluación

Funcionamiento correcto del consumo de la API.

Uso adecuado de useState para manejar estados y eventos.

Presentación clara y visualmente atractiva de las noticias.

Buen manejo de errores y mensajes informativos.

Orden, legibilidad y estructura del código fuente.

Calidad general del diseño y documentación en GitHub.
